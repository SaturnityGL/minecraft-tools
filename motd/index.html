MOTD questions

    
How do I change my Minecraft server MOTD?

    
Edit the motd= line in server.properties, save, and restart. Paste the line from the server.properties tab.

    
Why do my hex colors turn into plain colors in server.properties?

    
The vanilla server.properties MOTD only understands the 16 legacy colors, so this tool swaps each hex color for the closest legacy one in that output. Hex colors need software or a plugin that reads them, such as a MiniMessage based MOTD plugin or a proxy config. Use the MiniMessage or section sign tabs for those.

    
How long can a Minecraft MOTD be?

    
A MOTD has two lines. The server list only shows roughly 270 GUI pixels per line, which is about 45 normal characters, and cuts off the rest. Narrow letters like i and l take less room and bold text takes more. The width meter on this page gives an approximate count.

    
How do I add a server icon?

    
Put a 64 by 64 pixel PNG named server-icon.png in the server folder, next to server.properties, and restart the server. The icon upload on this page is only a preview in your browser and nothing is sent anywhere.

    
What do the &k, &l and &r codes do?

    
&k makes text obfuscated, which scrambles into random characters. &l is bold, &m is strikethrough, &n is underline, &o is italic, and &r resets everything back to plain. Picking a color code also clears any formatting that came before it, so add the format codes after the color.

    
Will my MOTD look the same on Bedrock or through Geyser?

    
Not exactly. Bedrock draws the server list differently and uses slightly different colors, and Geyser has its own MOTD settings in its config file. Treat the preview here as the Java Edition server list.
