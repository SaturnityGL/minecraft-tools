How to use these commands

Chat or command block

For short commands, open chat with T or /, paste, and press Enter. Chat stops at 256 characters, so anything longer needs a command block. Get one with /give @p command_block, place it, paste the command without the leading slash, and power it with a button or lever.

Cheats and permissions

You need cheats enabled in a singleplayer world, or operator permission on a server. Command blocks also need creative mode to edit, and on a server enable-command-block has to be true in server.properties.

Why the version matters

  • 1.21.5 and newer: names are written as SNBT, like custom_name={text:"Hi",color:"red"}. Entities take CustomName:{text:"Hi"} instead of a JSON string.
  • 1.20.5 to 1.21.4: items use bracket components, but names are still JSON strings like custom_name='{"text":"Hi"}'. The max health attribute lost its generic. prefix in 1.21.2.
  • 1.13 to 1.20.4: items use NBT tags like potion{CustomPotionEffects:[...]}. Effect ids in those tags were numbers until 1.20.2 and are namespaced names after.

Selectors and positions

@p is the nearest player, @s is whoever runs the command, @a is everyone. In a position, ~ means the spot where the command runs, and ~ ~1 ~ is one block up.

Nothing leaves your browser

The generator runs locally. No signup, no upload, nothing sent anywhere beyond the site-wide analytics you already agreed to in the cookie popup.

FAQ

How do I use the command in Minecraft?

Open chat with T or the slash key, paste the command and press Enter. You need cheats turned on in your world, or operator permission on a server. If the command is over 256 characters, put it in a command block instead.

Why does the tool warn about 256 characters?

The chat box stops at 256 characters, so long summon and potion commands get cut off. A command block holds far more. Paste the command in without the leading slash and power the block.

Which game version should I pick?

Pick the one that matches your game. 1.21.5 and newer uses SNBT text components, 1.20.5 to 1.21.4 uses item components with JSON-string names, and 1.13 to 1.20.4 uses the old NBT tags. If a command fails with a parse error, the version is the first thing to check.

Can I make an effect last forever?

Yes, on Java 1.19.4 and newer. The effect command takes the word infinite instead of a number of seconds, and potion effects use a duration of -1. On older versions use a long duration instead, up to 1000000 seconds in the effect command.

Does this work for Bedrock Edition?

No. Bedrock uses different command syntax and does not take NBT or item components in these commands. This generator only writes Java Edition commands.

Why is my custom potion name in italics?

Items with a custom name show in italics by default. The generator adds italic false to the name unless you tick the italic box.
