Redstone Sequencer

Click cells to set which lanes fire on each step. Pick your substrate and on-block, then export the schematic. Reads out as a stepped ROM: one step per row along +Z, one lane per column along +X.

How this reads out in-game

The schematic places a two-layer strip: substrate blocks at Y=0 across the full grid, and on-blocks at Y=1 only where you clicked a cell. Each row along +Z is one step; each column along +X is one lane (one output).

To sequence it, run a moving pulse along +Z on top of the strip (an observer clock, a comparator loop, or a mob head on ice pushed by pistons). At each step position, a comparator or observer above the on-block turns the cell into a pulse on that lane's output line.

Common uses

  • Note block songs. Each lane feeds a note block tuned to a different pitch. Steps = beats.
  • Firework shows. Each lane triggers a different color launcher.
  • Farm cycles. Lanes drive dispensers, pistons, or bone-meal for staggered plant tick timing.
  • Assembly programs. A read pulse across the whole strip pulls out one instruction word at a time.
