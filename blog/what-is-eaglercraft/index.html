What is Eaglercraft, and why can't it join normal servers?

Short version: Eaglercraft is old Minecraft Java (mainly 1.8.8) ported to run in a web browser. Singleplayer works in the tab. Multiplayer only works on servers running the Eaglercraft plugin, so it can't join Hypixel, Realms, or normal servers. It isn't official, and Mojang has been sending takedowns at it for years.

If you've been near a school Chromebook in the last few years, you've probably seen someone playing Minecraft in a browser tab. That's Eaglercraft. It's not a knockoff or a "Minecraft-like" game, it's the real old game running somewhere it was never meant to run.

What it actually is

A dev who goes by lax1dude took the Minecraft Java code and compiled it into something a browser can run (using a tool called TeaVM, if you care). The first version was 1.5.2. The big one is EaglercraftX, which is 1.8.8, and there's a 1.12.2 build floating around too.

So you get the actual 1.8 game. Same physics, same redstone, same mobs, same world gen. Your singleplayer worlds save into the browser's own storage, and you can export them as a file if you want a backup.

Because it's just a webpage (sometimes literally one HTML file), it runs on stuff that can't run normal Java Minecraft, like locked-down Chromebooks. That's the whole reason it blew up.

Why it can't join normal servers

This is the question everyone ends up asking, so here's the deal.

Regular Minecraft talks to servers over a plain network connection. Browsers aren't allowed to open those, so Eaglercraft uses WebSockets instead, which is the same kind of connection a web chat uses. A normal Minecraft server has no idea what to do with that.

For an Eaglercraft player to get in, the server has to install a plugin (EaglerXServer, it runs on BungeeCord, Velocity, or Spigot) that translates between the two. Most servers don't have it, and big ones aren't going to add it.

Then there's the login problem. Eaglercraft has no Microsoft account sign-in, so servers that accept it are letting people in without Mojang checking who they are. Same deal as cracked servers: anyone can type any name, so those servers usually make you /register a password the first time you join.

Put together:

  • Eaglercraft servers: yes
  • Hypixel, Realms, your friend's normal server: no
  • Bedrock servers and consoles: no

What's missing compared to the real current game

1.8.8 came out in 2015. A lot has happened since. No elytra, no shields, no Nether update, no caves and cliffs, no axolotls, no copper anything. Combat is the old spam-click style from before 1.9, which some PvP players actually prefer, so that one's a wash.

Is it legal? Is it safe?

Legal: it's Mojang's code being used without Mojang's permission. Mojang has sent waves of DMCA takedowns at the GitHub repos and asked Google to drop sites from search. That's why the "official" links keep dying and the mirrors keep moving. Nobody's coming after a kid on a Chromebook, but it's not a legit product and I'm not going to pretend it is.

Safe: the client itself is a webpage running in your browser's sandbox, so it's way less risky than downloading some random cracked launcher .exe. The danger is the mirror sites. Lots of them are wrapped in aggressive ads, popups, and fake download buttons. Real Eaglercraft is HTML. If an "Eaglercraft" site hands you an .exe or a browser extension, close the tab.

Running a server that lets Eaglercraft players in

If you run a Java server and your friends are stuck on Chromebooks, EaglerXServer can put both kinds of players on the same server. Big caveat: you're letting in players that Mojang hasn't verified, so you need a login plugin and you should assume people will try to join under other people's names. Read the project's own setup docs, the config changes between versions.

Should you play it?

If you're on a device that can't run the real thing and you just want to build some stuff, sure, it's a neat piece of engineering. If you can buy the actual game, do that. You get the current version, the real server list, and your own skin that other people can see.

Questions people ask

What version of Minecraft is Eaglercraft?

The main version, EaglercraftX, is Minecraft Java 1.8.8. The original release was 1.5.2, and there's also a 1.12.2 build.

Can Eaglercraft join Hypixel or normal servers?

No. Eaglercraft connects over WebSockets and has no Microsoft login, so it can only join servers running the EaglerXServer plugin. Hypixel, Realms, and normal servers don't accept it.

Does Eaglercraft save my worlds?

Singleplayer worlds save in your browser's storage. Clearing site data or switching browsers can lose them, so export a backup if you care about a world.

Is Eaglercraft a virus?

The real client is a webpage that runs in your browser, which is fairly low risk. The risk is the mirror sites, which are often covered in aggressive ads. If an Eaglercraft site hands you an .exe or a browser extension, don't run it.

Why do Eaglercraft sites keep disappearing?

Mojang has sent repeated DMCA takedowns at Eaglercraft repos and asked search engines to delist sites, so links move around a lot.
